# AI 与古酒 · 诗还在，酒却远了

十四幕中文水墨展演，用于课堂演示、替代 PPT。主题是中国古酒的历史线索、AI 辅助复原的可能与证据边界。

网站：https://liu123-edg.github.io/gujiu-time/

## 播放

直接打开 `index.html` 即可离线使用，不需要安装依赖，也不加载外部字体或动画库。亦可在项目目录运行 `python -m http.server 4173`，浏览器访问 `http://localhost:4173/`。

| 操作 | 效果 |
| --- | --- |
| →、空格、Page Down | 下一幕 |
| ←、Page Up | 上一幕 |
| Home / End | 封面 / 资料幕 |
| F / 右上角全屏按钮 | 全屏切换；Esc 退出 |
| 顶部章节、右侧圆点 | 跳到指定章节或幕次 |
| 手机左右滑动 | 翻幕；上下滑动保留给长内容 |

转场期间忽略重复翻幕，不积累操作队列。刷新从 URL 的 `#1` 至 `#14` 恢复；没有幕次时尝试恢复同一标签页的上次位置。要重新观看开场，请访问 `/#1` 或点击左上角标识。最后一幕的答疑可展开。

## 十四幕

1. 庭院开场：AI 与古酒。
2. 陶渊明与李白：诗里的举杯瞬间。
3. 古代的酒不止一种：时代、地域、原料、工艺。
4. 诗还在，酒却远了：深墨色情绪转折。
5. 消逝的四个层面：酒液、条件、场景、感受。
6. 历史留下的线索：古籍与考古残留物。
7. 由文字追到工艺：研究问题地图。
8. 历史证据的空白：不能靠想象补齐。
9. AI 整理线索：古籍、工艺与实验记录的关联。
10. 从假设走向实验：依据、对照、记录与修正。
11. 证据边界：文献记载、合理推断、待验假设、历史体验。
12. 如果复原出一杯：它依然诞生在今天。
13. 回到庭院：复原出来的，就是原来的酒吗？
14. 答疑与可核查资料。

## 文件与视觉实现

- `index.html`：可直接编辑的中文内容、SVG 图表与参考链接。
- `styles.css`：宣纸色、投影排版、各幕构图、开场分层揭示与响应式布局。
- `app.js`：翻幕状态、URL 恢复、全屏、触控、辅助功能，以及程序化墨迹。
- `assets/courtyard.webp`：水墨庭院主画，开场与结尾复用。素材说明与完整提示词见 `assets/ARTWORK.md`。
- `assets/ink-reveal.svg`：含噪声位移的开场揭示遮罩。
- `assets/paper.svg`：纸张颗粒。

庭院是分层背景艺术素材，文字和研究图表保持原生网页元素。开场用三个有不同起笔位置的 SVG 遮罩逐步展开，并作缓慢镜头移动。翻幕使用 Canvas：多尺度噪声生成颜料纹理，墨团从一侧扩散，伴随飞溅与湿润晕边；完全覆盖后换幕，再以不规则扩散擦除揭示下一幕。动画并非视频或矩形遮罩。

转场画布宽度上限 1280 像素；六张程序化颜料纹理只生成一次。仅转场期间请求 Canvas 动画帧。旧幕退出后取消其 CSS 入场动画；窗口缩放、切到后台等情况会结束当前转场并释放状态锁。系统开启“减少动态效果”时，禁用墨迹与推进动画，保留全部内容和导航。隐藏幕设置 `inert`，避免键盘焦点进入隐藏内容。

## 内容边界与参考

不声称所有古代酿酒技术失传；不统一标注古酒的酒精度、味道；不推定诗人饮用的具体酒液。不把 AI 假设当成史实，也不虚构 AI 复原案例或实验结果。工艺图是研究问题示意，庭院是诗意创作。

1. 陶渊明：《饮酒》其五。[中国古诗文精读](https://www.classicalchineseliterature.org/article.php?article=%E9%A3%B2%E9%85%92%EF%BC%88%E5%85%B6%E4%BA%94%EF%BC%89)。仅用于诗意引入。
2. 李白：《月下独酌四首》其一，《全唐诗》卷一百八十二。[中国哲学书电子化计划](https://ctext.org/text.pl?if=gb&node=139787)。仅用于诗句查阅。
3. 贾思勰：《齐民要术》卷七。[《齐民要术校释》电子文本](https://ctext.org/wiki.pl?chapter=298016&if=en&remap=gb)。涉及制曲、造酒；如开展具体工艺研究，还需核对影印底本、条目及异文。本展演未引用具体配方。
4. 朱肱：《北山酒经》（《酒经》）。[中国哲学书电子化计划](https://ctext.org/wiki.pl?if=gb&res=187933)。仅作工艺文献线索，不等同更早时期的技术。
5. Wang, J., Liu, L., Ball, T., Yu, L., Li, Y., & Xing, F. (2016). Revealing a 5,000-y-old beer recipe in China. *PNAS*, 113(23), 6444–6448. [DOI: 10.1073/pnas.1601465113](https://doi.org/10.1073/pnas.1601465113)。用于说明残留物分析可以支持对原料和酿造活动的判断；该论文不是 AI 复原案例。

资料链接已通过搜索结果与文献元数据核对；部分古籍站点会对自动访问返回 403，未将未核实的具体工艺写成事实。
