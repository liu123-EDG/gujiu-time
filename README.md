# 古酒与时间｜沉浸式网页展演

## 本地预览
直接双击 `index.html` 用现代浏览器打开即可。使用 ← / →、空格或底部按钮翻幕。

## 发布到你现有的 GitHub 账号（不触碰旧网站）
1. 登录 https://github.com
2. 点击右上角 `+` → `New repository`
3. Repository name 填 `gujiu-time`（或你喜欢的名字）
4. 选择 Public，勾选 Add a README 可选，然后 Create repository
5. 在新仓库页面选择 `Add file` → `Upload files`，上传本文件夹里的 `index.html` 和 `README.md`，点击 Commit changes
6. 进入新仓库 Settings → Pages
7. 在 Build and deployment 中选择 `Deploy from a branch`，Branch 选 `main`，文件夹选 `/(root)`，保存
8. 等待部署完成。通常网址会是 `https://liu123-edg.github.io/gujiu-time/`

重要：只在新建的 `gujiu-time` 仓库中操作，不要修改或删除 `xiangmai` 仓库。
